# ServerEyes — binarios públicos (descargas)

Este repositorio aloja **solo los binarios de descarga** de ServerEyes (APK móvil y,
cuando corresponda, el agente/cliente de Windows), para que sean públicamente
accesibles y el **código fuente** pueda quedar en un repositorio privado.

- **APK móvil**: último release → `releases/latest`.
- Los binarios se publican como *release assets*.
- La **autenticidad de las actualizaciones** del agente se verifica por **firma
  HMAC (por máquina) + sha256**, no por la visibilidad de este repositorio.

Este repo **no contiene código fuente**.
